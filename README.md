# 🏏 Street Cricket 2D Game

A lightweight, browser-based 2D street cricket mini-game built using **HTML5 Canvas**, **CSS3**, and **JavaScript**.

## Features
- Interactive 2D pitch canvas.
- Real-time batting mechanics with Spacebar or Button controls.
- Randomized outcomes (1s, 2s, 4s, 6s, and Wickets).
- Score and Wickets tracking over 12 balls.

## How to Run Locally
1. Clone the repository or download the source code.
2. Open the folder in **Visual Studio Code**.
3. Install the **Live Server** extension in VS Code.
4. Right-click `index.html` and select **"Open with Live Server"**.
